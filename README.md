# 仕途面试通

可在本机和同一局域网运行的公务员面试课程模拟网站。提供考生、考官（含主考官）、管理员三个视角，以及结构化面试和无领导小组面试。

本仓库只发布网站源码、自动化检查代码和运行说明。实验报告、UML、原型图和报告生成材料保留在本地 `docs/`，由 `.gitignore` 排除；数据库、证书和密钥也不进入版本管理。

## 快速启动

需要 Python 3.11 或更高版本。推荐 Chrome 或 Edge。

Windows 双击 `start.cmd`，或在 PowerShell 中运行 `./start.ps1`。首次启动会创建项目自己的虚拟环境并安装依赖。Linux / macOS 使用 `sh start.sh`。

也可以手动运行：

```shell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe lan.py
```

在 macOS/Linux 中将 `.venv\Scripts\python.exe` 改为 `.venv/bin/python`。

- 本机入口：`http://localhost:5200`
- 局域网 HTTPS：`https://服务器局域网IP:5443`，启动时打印实际地址。
- 不需要云服务器，也不需要付费服务。首次安装依赖需要联网，安装后网站资源全部来自本机。
- 关闭启动窗口或按 Ctrl+C 停止服务器。重新启动会保留数据。

若只演练文字流程，可以运行 `python app.py`，仅开启 5200 端口的 HTTP 服务。

## 局域网音视频准备

浏览器允许 localhost 使用媒体设备，但其他设备通过普通 HTTP 的局域网 IP 访问时通常不能开启摄像头或麦克风。实际通话应使用可信 HTTPS。

1. 所有设备连接同一个局域网。运行 `lan.py`，服务器同时提供 HTTP 5200 与 HTTPS 5443。
2. 脚本在 `.local/tls/` 生成专属于本项目的本地 CA 和服务器证书；不会自动安装信任，也不会修改防火墙。
3. 只将 `.local/tls/classroom-ca.crt` 复制到你管理的参与设备。不要复制 `ca.key` 或 `server.key`。
4. 在每台参与设备上手动信任该证书。Windows 可双击证书 → 安装证书 → 当前用户 → 将所有证书放入指定存储 → 受信任的根证书颁发机构。重新打开浏览器后使用启动窗口列出的 HTTPS 地址。
5. macOS 可在钥匙串中导入并为该课程证书设置 SSL 信任。iOS 安装描述文件后还需要在证书信任设置中启用；Android 的用户 CA 支持受设备及浏览器策略影响。优先使用 Windows/macOS 桌面浏览器完成课程演练。
6. 如系统防火墙询问是否允许 Python，只对参与课堂的专用网络开放。不要把端口映射到公网。Wi-Fi 的客户端隔离可能阻止设备直连。
7. 证书地址不匹配时，重新启动生成包含当前 IP 的服务器证书；可用 `python lan.py --ip 192.168.1.10` 显式添加局域网地址。CA 有效期一年，服务器证书最长 90 天，启动时自动重新签发服务器证书。

证书仅用于你管理的课堂环境，课堂结束后可在设备的证书管理器中删除 `Interview Lab Local Classroom CA` 的信任。不要通过忽略浏览器安全警告来代替正确配置。

WebRTC 默认使用同一局域网内的直接连接，不配置外部 STUN/TURN。跨 NAT 或受隔离网络不在本版范围内。组内使用耳机以避免扬声器回声。

## 一次完整练习

1. 管理员创建房间，指定考生、1–3 位考官、主考官、题目、计划时间与总时长。结构化面试为 1 位考生；小组面试为 2–6 位考生。
2. 考生进入候考房间，检查摄像头、麦克风、扬声器和网络后确认就绪。自检不建立通话，不启动答题计时。新房间默认要求设备自检；管理员可明确启用文字演练。
3. 主考官在本人和全部考生准备好、达到计划时间后，确认正式开始。系统展示题目并启动全场计时。
4. 每位参与者主动点击“连接音视频”。这一步才会发送媒体。设备自检中的预览只在本地显示；服务器不录制音视频，也不自动转写语音。
5. 结构化面试由主考官切题；小组面试按个人陈述、自由讨论、总结陈述推进。考生可以写个人笔记、举手、发送公共观点、申请延时、提交文字作答要点。
6. 主考官可以暂停、恢复计时并批准 60 秒延时。所有题目与小组阶段共用全场倒计时；时间到零后不再接收答案，由主考官确认结束。
7. 考官选择考生并独立暂存六维分数与评语；内部频道用于考官沟通与合议。考生和管理员都不能读取内部沟通，其他考官也不能读取本人的评分草稿。
8. 面试结束后，考官补齐各项并提交最终评分，提交后锁定。主考官收齐全部考生的全部考官评分后归档公布。
9. 考生回顾自己的成绩和评语，或导出自己的 CSV；考官和管理员可导出其有权访问房间的成绩。

预置房间允许文字演练，历史成绩是明确标记的合成教学样例。文字演练就绪不代表真实设备已通过检查。

## 设备与断线处理

- 自检请求 1280×720 摄像头画面，显示设备实际提供的分辨率；未达到 720p 不记录为设备就绪。
- 麦克风检查读取本机音量，需实际检测到声音；扬声器由参与者播放测试音并确认听清。
- 设备权限等待 20 秒后显示超时；即使旧请求晚到，也会释放其中的媒体轨道。
- 关闭摄像头/麦克风按钮真实切换轨道状态；切换摄像头使用 `replaceTrack` 更新已建立的通话。
- 断网时保留输入，恢复后重新请求状态；媒体断线会尝试重建连接，也提供手动重新连接。
- 草稿按“账号＋房间＋类型”保存在本机浏览器；保存到服务器后移除本机草稿。使用共享电脑时不要在同一浏览器留下私人练习内容。
- 离开房间或面试结束会关闭通话并停止设备轨道；断开通话时可以保留本地预览。
- 200ms 本地预览延迟是课程性能目标，本版没有把网络往返时间当作已测得的预览延迟。

“使用指南 → 浏览器连接诊断”提供合成画面与静音音轨的同浏览器 WebRTC 检查，不申请真实设备权限。它验证编码、连接和解码，不替代两台实体设备的局域网试验。

## 评分规则

综合分析能力、沟通表达能力、逻辑思维能力、应变能力、团队协作能力、仪表举止，各项 0–100 分。先对六维取等权平均，再对全部考官取算术平均，保留两位小数。该规则是课程模拟规则，不宣称为真实招录考试的统一评分办法。

暂存允许缺项；最终提交须六项完整、评语至少六个字且房间已结束。公开归档前必须收齐所有考官对所有考生的评分。不存在由系统自动作出录用决定的功能。

## 项目结构

| 文件 | 用途 |
| --- | --- |
| app.py | HTTP 接口、角色授权、状态转换、评分和信令校验 |
| db.py / schema.sql | SQLite 初始化、独立教学样例、外键与唯一约束 |
| lan.py | 项目内证书生成与 HTTPS 启动，不修改系统信任 |
| static/app.js | 三角色页面、设备自检、WebRTC、交互与草稿保护 |
| static/styles.css | 响应式布局与中文视觉样式 |
| static/diagnostics.html | 合成媒体连接诊断 |
| tests/test_workflow.py | 临时数据库中的业务与权限检查 |
| start.cmd / start.ps1 / start.sh | 启动入口 |

数据保存在 `.local/interview.sqlite3`，会话密钥在 `.local/session.key`。如果要重新开始演练，先停止服务器，备份并重命名 `.local/interview.sqlite3` 及其存在的 `-wal`、`-shm` 文件，再启动生成新库。不要在服务运行时直接改动数据库。

与好差评项目独立：目录、虚拟环境、数据库、5200/5443 端口与 `interview_lab_session` Cookie 均隔离，无跨目录代码依赖。

## 主要接口

| 方法及路径 | 用途 |
| --- | --- |
| GET /api/session；POST /api/login /api/register /api/logout | 会话与身份 |
| GET/POST /api/rooms；GET /api/rooms/{id} | 分配房间、创建与详情 |
| POST /api/rooms/{id}/ready | 设备或明确文字演练就绪 |
| POST /api/rooms/{id}/control | 主考官开始、暂停、恢复、切换、结束、公布，需 version |
| POST /api/rooms/{id}/note /answer /message /hand /extension | 笔记、答案、沟通、举手和延时 |
| POST /api/rooms/{id}/scores | 独立暂存或提交评分 |
| POST /api/rooms/{id}/presence /signal | 在线心跳与授权后的 WebRTC 信令 |
| GET /api/history；GET /api/export/{id} | 按权限回顾与导出成绩 |

所有写接口需要会话中的 CSRF 令牌（请求头 `X-CSRF-Token`）。身份、房间成员、角色、状态和版本在服务端校验。SQLite WAL、唯一约束与事务防止重复和状态覆盖。CSV 文本字段防止电子表格公式注入。

## 开发检查与已知边界

```shell
python -m unittest discover -s tests -v
```

检查使用临时库，覆盖身份与房间权限、候考题目保护、暂停延时、评分完整性及归档、私有笔记与内部消息、小组阶段、信令身份和 HTTPS 证书验证。不会写入正常演练数据。

本版适用于受控局域网课程模拟，采用 1.5 秒信令轮询与 3 秒房间状态轮询，音视频本身由 WebRTC 传输。它不是正式远程招录平台。真实设备、双机网络效果和预览延迟需在实际设备环境中验证；本次交付按要求不进行真实摄像头/麦克风测试。不提供真实身份核验、人脸识别、录制、语音转写或自动录用判断。生产公网服务还需独立的账号治理、限流、审计和运维方案。
